These pages send users to search.html?area=City and preserve the established form behaviour.

BEFORE publishing: check that current live search.html accepts the `area` query parameter and that paths to pricing.html and treatments.html still match. The template is a saved October 2026 version, not necessarily the latest live site.

After publishing: add the six absolute page URLs to the live sitemap.xml and optionally link them from your main site, then test on mobile and desktop. Do not overwrite existing sitemap without checking its current contents.

Note: local neighbourhood cards are navigation prompts for searching that city; they do not assert that therapists currently exist in those neighbourhoods.
