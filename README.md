# MassageMatch UK — Prototype v0.1

Initial front-end foundation for massagematch.uk.

## Included
- Responsive homepage
- Therapist search UI
- Clearly-labelled example profiles
- Treatment categories
- Founder story
- Founding therapist offer
- Profile-builder preview
- Therapist dashboard preview

## Run locally
Open `index.html` in a browser.

## GitHub Pages preview
This is static HTML/CSS/JS and can be previewed with GitHub Pages while development continues. Keep the custom massagematch.uk domain disconnected until launch.

## Next build
Authentication, real therapist profile creation, image uploads, database, admin approval workflow, location search, and later subscription payments.
